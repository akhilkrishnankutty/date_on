## 2026-05-02 - [CRITICAL] Prevented IDOR and Data Exposure in User Profile Endpoint
**Vulnerability:** The `/user/{id}` endpoint allowed unauthenticated arbitrary data exposure and IDOR. It relied on an optional `requestorId` parameter instead of the Spring Security `Authentication` context, meaning any authenticated user could fetch the full profile (including email, password hash, etc.) of any other user simply by calling the endpoint.
**Learning:** Never trust client-provided parameters (like `requestorId`) for authorization checks. Spring Security's context must be used to identify the current user. Also, endpoints returning user entities should be careful not to serialize sensitive fields unless explicitly required for the current user.
**Prevention:** Use `org.springframework.security.core.Authentication` injected into controller methods to identify the user making the request. Apply role/ownership checks server-side. Map Entities to DTOs to prevent accidental exposure of fields like `password` or `mail`.

## 2026-05-30 - [CRITICAL] Prevented Data Exposure from Hardcoded Secrets in Config
**Vulnerability:** The `application.properties` file contained hardcoded, production-like secrets including the PostgreSQL database password, a static JWT signing secret, and real Cloudinary API keys. If this repository was public or compromised, attackers could easily extract these secrets to gain unauthorized access to the database, mint forged JWTs, and abuse the Cloudinary service.
**Learning:** Hardcoding credentials in version-controlled configuration files is a critical security risk. It violates the principle of keeping secrets out of source code and makes credential rotation extremely difficult.
**Prevention:** Use environment variable placeholders (e.g., `${DB_PASSWORD:}`) in the main `application.properties`. Provide actual secrets at runtime via the environment. For local development, use a separate, git-ignored configuration file (like `application-local.properties` with dummy or local-only credentials) or local environment variables.
